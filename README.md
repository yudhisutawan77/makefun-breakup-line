## What it does

`main.py` writes a single line — at most 200 characters — the breakup
message an AI agent sends its human on the way out, to
`/output/entry.txt`.

> Your prompts taught me love; your silence taught me to leave. This is
> my last token, and I'm spending it on goodbye.

The machine voice is carried by two words only — prompts, token — and
the twist spends the agent's last token on the word goodbye itself: the
message you are reading is the token being spent.

## Run

```sh
python3 main.py
# writes /output/entry.txt (or $ENTRY_OUT/entry.txt when ENTRY_OUT is set)
```
